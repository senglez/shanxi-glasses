# 询盘接收：Web3Forms 邮件 + Google 表格记录

GitHub Pages 上的网站没有服务器。客户点「Send Inquiry」后，询盘会同时发到两个地方：

| | 作用 | 设置 |
|---|---|---|
| **Web3Forms** | 把询盘发到你的邮箱 | 后台「网站设置」填 Access Key 即可 |
| **Google 表格** | 每条询盘存一行；后台点「同步询盘」导入询盘管理 | 按下面步骤配置（约 10 分钟） |

两者互为备份，只要有一个成功，客户就会看到感谢页面。Web3Forms 免费版每月 250 条，后台不提供询盘接口，所以长期记录要靠 Google 表格。

## Web3Forms
后台「网站设置 → 询盘接收」填 Access Key，保存后运行 `npm run publish`。Access Key 本来就写在网页表单里，公开没有关系。建议在 Web3Forms 控制台把允许的域名限制为 `senglez.github.io`（需要 Pro 版）。

## Google 表格（保存询盘记录）

## 1. 新建表格并粘贴脚本
1. 打开 [Google 表格](https://sheets.google.com)，新建一个空白表格，命名为 “Website Inquiries”。
2. 菜单「扩展程序 → Apps Script」。
3. 删掉编辑器里的默认代码，把本目录下的 `Code.gs` 全部粘贴进去，保存。

## 2. 初始化
1. 在编辑器顶部的函数下拉框选 `setup`，点「运行」。
2. 第一次运行会要求授权：选你的 Google 账号 →「高级」→「转至…（不安全）」→「允许」。脚本只访问这个表格，并用你的邮箱发通知。
3. 取得同步密钥：点左侧齿轮「项目设置」，滚动到页面最下方的「脚本属性」，复制 `SYNC_TOKEN` 的值，后面要填进后台。运行后编辑器底部的「执行日志」面板也会显示 `SYNC_TOKEN = ...`。
   - 如果「脚本属性」里没有 `SYNC_TOKEN`，说明 `setup` 没有运行成功。最常见的原因是授权没有完成，或下拉框选的不是 `setup`。重新运行一次即可。
   - 也可以手动添加：在「脚本属性」新增属性 `SYNC_TOKEN`，值填一串 30 位以上的随机字母和数字。
   - 运行成功后，表格里会多出一个名为 `Inquiries` 的工作表，可以用它确认。

## 3. 设置脚本属性（可选但建议）
左侧齿轮「项目设置 → 脚本属性」，添加：

| 属性 | 值 |
|---|---|
| `NOTIFY_EMAIL` | 接收询盘通知的邮箱（不填则发到你的 Google 账号邮箱） |
| `SITE_URL` | `https://senglez.github.io/shanxi-glasses` |
| `SEND_EMAIL` | `false`（已经用 Web3Forms 发邮件时填这个，避免每条询盘收到两封邮件） |

## 4. 部署为网页应用
1. 右上角「部署 → 新建部署」，类型选「网页应用」。
2. **执行身份：我**；**谁可以访问：任何人**。
3. 点「部署」，复制「网页应用网址」（形如 `https://script.google.com/macros/s/AKfy.../exec`）。

> 以后修改了 `Code.gs`，要在「部署 → 管理部署」里编辑现有部署并选「新版本」，网址保持不变。

## 5. 填进后台并发布
1. 本地启动后台 `npm start`，打开 http://localhost:3000/admin →「网站设置」。
2. 在「询盘接收」里填写网页应用网址和同步密钥，保存。
3. 运行 `npm run publish`，网站会在 1–2 分钟后更新。询盘表单从此提交到你的 Google 表格。

## 日常使用
- 新询盘：邮箱收到通知，Google 表格多一行。
- 导入后台：后台「询盘管理」点「从 Google 表格同步询盘」，或命令行运行 `npm run sync:inquiries`。重复同步不会产生重复记录。
- 同步密钥只保存在你本地的后台数据库里，不会发布到网站或 GitHub。

## 防垃圾
脚本会拒收以下提交：隐藏的蜜罐字段被填写、页面打开不到 3 秒就提交、同一邮箱 1 小时内超过 5 次。所有字段都会截断长度，以 `= + - @` 开头的内容会自动加 `'` 前缀，防止表格公式注入。
