# 询盘接收：Google 表格 + Apps Script（约 10 分钟）

GitHub Pages 上的网站没有服务器。客户提交的询盘会发到你自己的 Google 表格，每条一行，同时发邮件通知你。本地后台点「同步询盘」就能把表格里的询盘导入询盘管理。

## 1. 新建表格并粘贴脚本
1. 打开 [Google 表格](https://sheets.google.com)，新建一个空白表格，命名为 “Website Inquiries”。
2. 菜单「扩展程序 → Apps Script」。
3. 删掉编辑器里的默认代码，把本目录下的 `Code.gs` 全部粘贴进去，保存。

## 2. 初始化
1. 在编辑器顶部的函数下拉框选 `setup`，点「运行」。
2. 第一次运行会要求授权：选你的 Google 账号 →「高级」→「转至…（不安全）」→「允许」。脚本只访问这个表格，并用你的邮箱发通知。
3. 运行完成后，点左侧「执行记录」可以看到 `SYNC_TOKEN = ...`。**复制这个同步密钥**，后面要填进后台。

## 3. 设置脚本属性（可选但建议）
左侧齿轮「项目设置 → 脚本属性」，添加：

| 属性 | 值 |
|---|---|
| `NOTIFY_EMAIL` | 接收询盘通知的邮箱（不填则发到你的 Google 账号邮箱） |
| `SITE_URL` | `https://senglez.github.io/shanxi-glasses` |

## 4. 部署为网页应用
1. 右上角「部署 → 新建部署」，类型选「网页应用」。
2. **执行身份：我**；**谁可以访问：任何人**。
3. 点「部署」，复制「网页应用网址」（形如 `https://script.google.com/macros/s/AKfy.../exec`）。

> 以后修改了 `Code.gs`，要在「部署 → 管理部署」里编辑现有部署并选「新版本」，网址保持不变。

## 5. 填进后台并发布
1. 本地启动后台 `npm start`，打开 http://localhost:3000/admin →「网站设置」。
2. 在「询盘接收」里填写网页应用网址和同步密钥，保存。
3. 运行 `npm run publish`，网站会在 1–2 分钟后更新。询盘表单从此提交到你的 Google 表格。

## 日常使用
- 新询盘：邮箱收到通知，Google 表格多一行。
- 导入后台：后台「询盘管理」点「从 Google 表格同步询盘」，或命令行运行 `npm run sync:inquiries`。重复同步不会产生重复记录。
- 同步密钥只保存在你本地的后台数据库里，不会发布到网站或 GitHub。

## 防垃圾
脚本会拒收以下提交：隐藏的蜜罐字段被填写、页面打开不到 3 秒就提交、同一邮箱 1 小时内超过 5 次。所有字段都会截断长度，以 `= + - @` 开头的内容会自动加 `'` 前缀，防止表格公式注入。
