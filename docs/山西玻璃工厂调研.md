## 三、对接建议

1. **按工艺分工厂**：手工吹制高脚杯、彩色/叠色器皿、高硼硅、机压杯子分属不同工厂，一个产品找 2–3 家对比报价。
2. **验厂清单**：营业执照与出口资质、窑炉数量和产线、日产能、质检流程、出货合格率、包装跌落测试、过往出口国家、可提供的检测报告（FDA / LFGB）。
3. **价格保密**：工厂价、报价、利润记录在后台询盘的「跟进备注」里，不要放到前台。
4. **注意定位冲突**：Alibaba 和 Made-in-China 上已有不少祁县工厂直接做外贸。网站的差异化要体现在：多工厂比价、混合拼柜、英文沟通、质检，以及更低的起订量。
